"# Vigil" : A Browser Extension for Awareness and Privacy
To use this extension:
1. Download the repository in a folder
2. "Extract All"
3. Open Extensions Manager in your browser
4. Turn on Developers' Mode
5. Select the option to 'Load Unpacked' and select the extracted Vigil folder
6. Your Vigil browser extension will be ready to use
7. For ease of access, pin Vigil in the extensions.
